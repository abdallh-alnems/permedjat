# أصول App Store — لوحة المالك

> ⚠️ **هذا التطبيق لا يستهدف iOS حالياً** — لا يوجد مجلد `ios/`
> في المشروع و `ios: false` في `pubspec.yaml`. المجلد موجود لتوحيد التقسيم
> مع بقية التطبيقات، ويُملأ يوم ما يُضاف هدف iOS.
